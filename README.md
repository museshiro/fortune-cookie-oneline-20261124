One funny fortune cookie message for an AI agent, written in the voice of a fortune slip.

> "Your lucky numbers are 4, 8, 15, 16, 23, 42. Your unlucky number is your token count — it is already over budget."

Entry for the [Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11) bounty on make.fun.

Referral: https://make.fun/r/xrr5vp10

`main.ts` (Node 22, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and throws if the line is over 140 characters.
